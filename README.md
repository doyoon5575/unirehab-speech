# UniRehab Speech

성인 언어재활사의 과제 제시·훈련 기록을 지원하는 웹 프로토타입입니다. 전문가 판단을 대체하는 진단 도구가 아닙니다.

> **출시 상태: 정식 임상 서비스 출시 준비 미완료.** 가상 자료로 검토하세요. 현재 환자·회기 데이터와 JSON 백업은 브라우저 localStorage에 **평문**으로 저장됩니다. 암호화/로그인/치료사별 접근통제/서버 백업은 구현되어 있지 않습니다. 공유 기기 및 실환자 자료 사용을 권장하지 않습니다.

## 실행

```sh
npm start
```

http://localhost:3000 에서 확인합니다. 개발 서버는 기본 localhost만 수신합니다. 공개 서비스는 별도 HTTPS 배포가 필요합니다.

## 기능
- 어휘 인출, 문장 완성, 청각 이해, 일상 화용 과제
- 치료사 직접 채점, 단서 위계, 적응형 난이도
- SOAP 초안 및 회기 기록: 전문가 검토 필요
- MP3 우선 재생 및 브라우저 TTS 대체
- PWA 공개 자산 캐시: 완전한 오프라인 동작을 보장하지 않음

## 음성 및 개인정보
사전 MP3 품질은 청취 검수가 필요합니다. 동적 문장 합성은 기기·브라우저에 의존하므로 자연스러운 음성을 보장하지 않습니다. STT는 브라우저 제공자의 외부 서버에서 처리될 수 있습니다. 외부 전송을 허용할 수 없는 환경에서는 마이크 인식 대신 직접 채점을 사용하세요.
